![Backolon logo](./images/icon.png) # Backolon A tiny, self-modifying homoiconic scripting language.
```backolon ## Hello World print "Hello, World!" ## List filtering, mapping, reducing ["hello", "world", "!"] |?> it != "!" |*> upper it |+>[""] _ + it ## -> "helloworld" ## Fizzbuzz let fizzbuzz = fn(n) n % 15 == 0 ? "fizzbuzz" : n % 5 == 0 ? "buzz" : n % 3 == 0 ? "fizz" : "{n}" foreach i in range(1, 100) print fizzbuzz i end ## yin yang puzzle let yinHelper = fn(char) fn(c) ((fn(cc) (print char; cc)) (callcc fn(c) c)) let yin = (yinHelper "*"), yang = (yinHelper "@") in yin yang end ```

## Homoiconic The `Block` mechanism allows functions to take code as arguments and manipulate its behavior in a hygienic manner, staying concise and readable. Expression ASTs are also just JSON, so unhygenic macros are still possible and just as easy.
## Keywordless Operators and control flow are ordinary functions rather than reserved keywords.
## Self-Extensible Backolon's syntax is (mostly) defined in Backolon itself, using a modified Pratt parser system allowing seamless modification of the grammar - mid-execution!
## First-class Continuations `return` is just a variable holding a continuation, making nonlocal jumps, backtracking, coroutines, and cooperative multitasking easy.
## Powered by JEB Backolon is syntactic sugar over a powerful Scheme-like evaluation engine. Lower-level access to this layer is easy and enables advanced optimizations, manually or algorithmically.
## Auditable JEB injects "audit events" into the code, that allow the host to prevent potentially dangerous things from happening (such as infinite loops or JavaScript injection).
## JS/TS Embedding Designed to be embedded in JavaScript applications for seamless scripting.
## Why Backolon? Backolon's extensible syntax makes it perfect for building domain-specific languages, such as configuration files, while also allowing full Turing-complete functions where traditional syntax falls short. The macro system allows for incredibly powerful configuration systems to be expressed without modifying Backolon's default syntax - but if the default isn't enough, Backolon makes adding custom parsers trivial.
